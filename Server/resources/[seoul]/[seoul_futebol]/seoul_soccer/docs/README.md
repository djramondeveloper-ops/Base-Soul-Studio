# seoul_soccer

seoul_soccer adds server-managed football matches to FiveM. Players can create lobbies, choose a pitch and ball, join teams, wear team uniforms, play with goalkeeper and tackle mechanics, and save match statistics.

The resource supports QBCore and ESX. Its interface is available in English, Turkish, Portuguese, Spanish, German, and Polish (`en`, `tr`, `pt`, `es`, `de`, `pl`).

Start with [Installation](installation.md), then adjust [Configuration](configuration.md). Server integrations are listed under [Exports](exports.md).
