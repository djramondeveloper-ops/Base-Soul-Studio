SEOUL PROP EDITOR - EXPORTS

Esta pasta recebe os bundles gerados pelo botao Publicar do editor.
Cada mapa gera:
- <mapa>.fxmanifest.lua
- <mapa>.client.lua
- <mapa>.json
- <mapa>.csv
- <mapa>.ymap.xml
- <mapa>.README.txt

O .ymap.xml e fonte para CodeWalker, nao um YMAP binario pronto para stream.
Para uso direto no FiveM, use o fxmanifest + client.lua gerados conforme o README do mapa.
